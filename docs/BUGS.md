# Ascend AI - Bug Tracking

This document tracks all known issues across the Ascend AI platform.

## Bug Severity Levels
- 🔴 **Critical**: Core functionality broken; must fix before release.
- 🟠 **High**: Core functionality affected; must fix within milestone.
- 🟡 **Medium**: Experience issue; fix before release.
- 🔵 **Low**: Cosmetic issue; fix in future sprint.

---

## 🔴 Critical Bugs

### BUG-001: AI Coach returns fallback responses
**Status:** Closed
**Description:** The AI coach returns generic placeholders instead of personalized advice.
**Expected:** The AI orchestrates a context-aware response based on User Profile, Goals, Daily Log, Meals, Workouts, and Memory.
**Owner:** TBD (Fixed)

### BUG-002: Nutrition logging does not update dashboard
**Status:** Closed
**Description:** Logging a meal updates the local state but the Dashboard calories/macros cards are hardcoded and do not reflect the newly added data.
**Expected:** Nutrition entries immediately update the Dashboard metrics (Calories, Protein, etc.) and save to Firebase.
**Owner:** TBD (Fixed)

### BUG-003: Steps disappear after navigation
**Status:** Closed
**Description:** Step count is tracked using local React state (`useState`) and resets to 0 when navigating away from the dashboard.
**Expected:** Step count persists to Firebase and reloads consistently across sessions and navigation.
**Owner:** TBD (Fixed)

### BUG-004: Notification engine missing
**Status:** Open
**Description:** The UI toggle for notifications exists, but there is no background scheduler for browser or email reminders.
**Expected:** Scheduled reminders are triggered for workouts, water, and sleep.
**Owner:** TBD

## 🟠 High Priority Bugs

### BUG-005: XP and Levels are placeholder values
**Status:** Closed
**Description:** The XP and Level progression system displays hardcoded values in the UI.
**Expected:** XP and Levels are calculated dynamically based on completed workouts, logged meals, and missions.
**Owner:** TBD (Fixed)

### BUG-006: AI Preferences do not affect responses
**Status:** Closed
**Description:** The user can select AI Tone (e.g., Strict, Motivational) in Settings, but the AI ignores this.
**Expected:** AI responses strictly adhere to the selected persona and formatting preferences.
**Owner:** TBD (Fixed)

### BUG-007: Mission Control is mostly static
**Status:** Closed
**Description:** The Mission Control module lacks live timer tracking, distance calculation, and XP rewards.
**Expected:** Real activity tracking with an active flow.
**Owner:** TBD (Fixed)

### BUG-008: Daily reset behavior missing
**Status:** Open
**Description:** The dashboard does not archive the previous day's data or prepare the dashboard for a new day at midnight.
**Expected:** Automated daily reset flow (archiving to history, generating reports).
**Owner:** TBD

### BUG-009: Daily/Weekly reports not generated
**Status:** Open
**Description:** AI summaries are not being generated automatically.
**Expected:** Nightly daily summaries and weekly progress reports generated by AI.
**Owner:** TBD

### BUG-010: Dashboard is largely static
**Status:** Closed
**Description:** Values for "Daily Score", "Workout", and "AI Insight" on the dashboard are hardcoded placeholder text instead of real computed values.
**Expected:** All dashboard cards read live aggregated data.
**Owner:** TBD (Fixed)
